# Architecture

The current project is a static web interface shell.

- HTML provides the application structure and page destinations.
- CSS provides the responsive dark glass interface.
- JavaScript handles navigation, file selection, local image preview, and metadata display.

No AI engine or backend is connected.

The original Android implementation references Jetpack Compose, NCNN, Vulkan, and Replicate. Those components require separate compatibility work before integration into this web project.
