About Alter X

WHAT IS ALTER X?

Image enhancement, with a focused workflow.

Alter X is an application project for enhancing and upscaling images through compatible AI processing engines. The reconstructed interface provides an image workspace, processing configuration, and result presentation.

Processing features remain disabled in this preview until their runtime and backend requirements are implemented and tested.
